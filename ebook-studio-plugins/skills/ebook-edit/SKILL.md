# ebook-edit

## Misión
El editor que pule antes de maquetar.

## Checklist de revisión
1. Voz AI: escanear prohibiciones de ebook-write (frases plantilla, "en el mundo actual", listas genéricas) → reescribir
2. Coherencia: nombres, tiempos verbales, promesas del outline cumplidas
3. Repeticiones: palabras/frases repetidas cerca → variar
4. Front matter: portada, copyright (© año Autor), TOC
5. Back matter: conclusión + CTA (ej: regalo, reseña en Amazon, newsletter)
6. Ortografía/gramática idioma del state
7. Longitud: total ≈ outline (±10%) → si difiere, avisar y ajustar
- Presentar informe: "Corregí X frases robóticas, Y repeticiones, Z typos. ¿OK?"
